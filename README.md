#Jobify | India Tech Career Portal

Jobify is a sleek, high-performance job listing platform built to showcase premium tech opportunities across India. This project features a curated database of 20 high-growth roles from top companies like Zomato, Swiggy, and TCS.
✨ Key Features
Localized for India: All job salaries are displayed in the Lakh/yr format to match Indian industry standards.
Regional Hubs: Dedicated location support for major cities including Bangalore, Hyderabad, Pune, Mumbai, Delhi NCR, and a special focus on Odisha.
Smart Search & Filters: A custom-built filtering system that allows users to find jobs instantly by:
Search: Company or Role names.
Experience: Fresher, Mid-Level, or Senior.
Domain: Development, Design, Data Science, or Cloud.
Interactive Application Flow: Includes a professional modal-based "Details" view where users can read full descriptions and submit a simulated application.
Fully Responsive UI: Crafted with Tailwind CSS for a premium, mobile-first experience.
🛠️ Technical Implementation
Frontend: HTML5 and modern CSS (Tailwind CSS) for a fast, responsive layout.
Logic: Pure JavaScript (ES6+) handles the data filtering, search functionality, and real-time UI updates.
Typography: Integrated 'Plus Jakarta Sans' via Google Fonts for a modern tech brand feel.
📂 Project Structure
index.html: The main entry point containing the UI structure, Tailwind styles, and the embedded JavaScript logic.
logo.png: Branding asset used in the navigation bar.
📍 Getting Started
Clone this repository.
Ensure you have a logo.png file in the root directory.
Open index.html in any modern web browser to view the portal.
